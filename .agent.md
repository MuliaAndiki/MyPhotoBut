## 2. Non-Negotiable Architecture & Security Rules

1. **Zero-Trust `X-API-SECRET` Boundary**:
   - Every `/api/v1/*` endpoint in `service/` is protected by `middleware.APISecret`.
   - `API_SECRET` must **NEVER** be prefixed with `VITE_` or exposed to client browser bundles.
   - Read `process.env.API_SECRET` **per-request inside `.handler()`** of TanStack Start `createServerFn` (`web/src/lib/api/server-fetch.ts`). Never read `process.env` at module top-level (Cloudflare Workers inject env per request).
2. **Direct-to-R2 Binary Upload (No File Proxying)**:
   - Never proxy binary images (`image/webp`, `image/png`, `image/jpeg`, `image/gif`) through Cloudflare Workers (`createServerFn`) or the Go Fiber server.
   - Always use the 3-step flow:
     1. Request presigned PUT URL (`POST /api/v1/booth/presign` or `POST /api/v1/templates/presign`).
     2. Upload `Blob` directly from the browser to Cloudflare R2 via HTTP `PUT`.
     3. Confirm metadata (`POST /api/v1/booth/sessions` or `POST /api/v1/templates`).
3. **100% Guest Photobooth + Passwordless Creator Auth**:
   - `/booth` and `/s/$shareCode` (`Module B: booth`) must remain **100% Guest / Zero-Login**.
   - Creator & Admin endpoints (`Module A: auth` & `Module C: template`) use passwordless **Email Magic Link** (`15m TTL`) or **Google OAuth 2.0** with **JWT Access + Refresh Token Rotation**.
4. **Safari/iOS-Safe Canvas Engine**:
   - **NEVER** use `CanvasRenderingContext2D.filter` (`ctx.filter`) for photo filters—it fails silently on iOS Safari.
   - Always use pixel manipulation (`ctx.getImageData()` + `Uint8ClampedArray` + precomputed 256-entry `Uint8Array` LUTs) and mathematical center-crop (`computeCenterCrop` at `11:7.5` slot aspect ratio) as specified in `docs/05-CANVAS-ENGINE.md`.
5. **Selective SSR in TanStack Start**:
   - `/booth` **MUST** set `ssr: false` in `createFileRoute('/booth')` because it relies on `navigator.mediaDevices.getUserMedia` and `HTMLCanvasElement`.
   - `/s/$shareCode` **MUST** keep SSR enabled (`loader` + dynamic `head`) to emit OpenGraph (`og:image`) and Twitter Card meta tags for social crawlers.

## 3. Dual-Theme Design Tokens & `"Parkinsans"` Rules

- **Primary & Display Font**: `"Parkinsans"` (Google Fonts `wght@300..800`), paired with `"JetBrains Mono"` (`font-tabular`) for countdowns, share codes (`MORA-8X2A`), and timestamps. Never use `Inter Tight`.
- **4 Core Brand Primitives (`desain.png`)**:
  - `--brand-lime`: `#D8FF54` (Acid Lime — Primary CTA, active shutter, highlight cards)
  - `--brand-lavender`: `#C575F8` (Electric Lavender — Secondary accent cards, tilted stickers, title highlights)
  - `--brand-obsidian`: `#181818` (Obsidian Black — Dark Theme canvas, text on Lime/Lavender/White, circular icon badges)
  - `--brand-white`: `#FFFFFF` (Crisp White — Light Theme canvas, contrast cards on Dark Theme)
- **Contrast Invariant**: Text on `#D8FF54` (Acid Lime) and `#C575F8` (Electric Lavender) must **ALWAYS** be `#181818` (Obsidian Black).
